# Images Folder

Place all local website images in this folder.

The website currently loads demo photos from Unsplash. If an online image fails, it falls back to the matching file below. Use **exact lowercase file names**.

| Section | File name |
|---|---|
| Hero banner | `hero.jpg` |
| About | `about-1.jpg`, `about-2.jpg` |
| Services | `service-haircut.jpg`, `service-hair-spa.jpg`, `service-colour.jpg`, `service-facial.jpg`, `service-nails.jpg`, `service-bridal.jpg` |
| Gallery | `gallery-1.jpg` to `gallery-8.jpg` |

## Guidelines

- Use only images you own or that are properly licensed (Unsplash, Pexels, Pixabay: check each licence).
- Do not copy photos from other salons' websites or social media.
- Keep each image under 300 KB (hero up to 500 KB). Compress at squoosh.app.
- Update the `alt` text in `index.html` when you replace an image.
